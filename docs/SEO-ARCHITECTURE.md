## 1. Executive SEO Architecture Overview

JDC Solar 2.0 transitions from a fragmented, unoptimized WordPress/Elementor setup (which lacked `<h1>` tags on 6 pages, lacked meta descriptions on 7 pages, and lacked local structured data) to a **100% pre-rendered, semantic, schema-rich SEO engine**.

Every page is engineered with:
1. Strict Single-`<h1>` Semantic Hierarchy.
2. Custom, Click-Optimized `<title>` and `<meta name="description">`.
3. Self-Referential Absolute Canonical URLs.
4. Comprehensive Schema.org JSON-LD `@graph` Structured Data.
5. Standardized 1200×630px OpenGraph and Twitter Card Social Assets.
6. Clean, lowercase, hyphen-separated URL slugs with permanent 301 redirect protection.

## 4. 301 Permanent Redirect Architecture (Preserving Inbound Equity)

To eliminate all 13 legacy 404 dead ends discovered in `research/SITEMAP.md` and preserve existing inbound backlinks, the Apache `.htaccess` file implements permanent 301 redirects:

```apache
# JDC Solar 2.0 Permanent 301 Redirect Rules
RewriteEngine On

# Canonical Host & HTTPS Enforcement
RewriteCond %{HTTPS} off [OR]
RewriteCond %{HTTP_HOST} ^www\.jdcsolar\.com$ [NC]
RewriteRule ^(.*)$ https://jdcsolar.com/$1 [L,R=301]

# Legacy URL Aliases & Dead Ends
Redirect 301 /about-us/              /about/
Redirect 301 /contact-us/            /contact/
Redirect 301 /project/               /projects/
Redirect 301 /our-projects/          /projects/
Redirect 301 /calculator/            /solar-calculator/
Redirect 301 /faq/                   /#faq
Redirect 301 /faqs/                  /#faq
Redirect 301 /detail-service/        /services/
Redirect 301 /team/                  /about/
Redirect 301 /residential-solar/     /services/residential-solar/
Redirect 301 /commercial-solar/      /services/commercial-solar/
Redirect 301 /industrial-solar/      /services/commercial-solar/
Redirect 301 /solar-water-pump/      /services/
Redirect 301 /elementor-9/           /

# Strip .html Extensions for Clean URLs
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteCond %{REQUEST_FILENAME}.html -f
RewriteRule ^(.*)$ $1.html [L]

# Exclude Legacy WordPress & Royal Addons Query Strings
RewriteCond %{QUERY_STRING} ^wpr_templates= [NC]
RewriteRule ^(.*)$ / [R=301,L]
```
